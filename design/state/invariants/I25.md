# I25

Status: active
Anchor: I25
Enforcement: instruction

## Statement

**No secret value reaches output or an image.** No secret-declared value appears on stdout, on stderr, in a log line, or in a layer of an image the product builds. Owner: Build types, PowerShell module. Enforcement: partial `[code]` for the module (`PSModule.requirements.md` R-SEC-001, R-SEC-002); `[instruction]` elsewhere
