Status: active
Anchor: I24
Enforcement: instruction

## Statement

**Generated environment files do not outlive the build.** Every environment file the build generates is removed on every exit path, success or failure. Owner: Build types. Enforcement: **partial `[code]`** — `forge/Common/Base.cs:244-251` (`DeleteGeneratedEnvFiles`) removes both `.build/.build.env` and the application environment file `.env` in the repository root (generated at `forge/Common/Components/INodeComponent.cs:48`) on process exit and on cancel, and `Cleanup` (`forge/Common/Base.cs:283-287`, called from `OnBuildFinished`) removes the same two on both build outcomes. A forcible kill that runs neither handler is not covered, and no test asserts the removal of either file after a build
