## Statement

**Generated environment files do not outlive the build.** Every environment file the build generates is removed on every exit path, success or failure. Owner: Build types. Enforcement: **partial `[code]`** — `forge/Common/Base.cs:244-250` removes `.build/.build.env` from `OnBuildFinished`, which NUKE runs on both outcomes. The application environment file generated at `forge/Common/Components/INodeComponent.cs:48` into the repository root is **not** removed by any path; closing that is a slice obligation, not an existing property
