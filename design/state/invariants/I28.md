## Statement

**A launcher does not reinterpret the build's outcome.** The global tool returns the container's exit status unchanged. The PowerShell module surfaces a non-zero status as a terminating error carrying that status (`PSModule.requirements.md` R-INVOKE-005). Neither maps one status onto another. Owner: Launchers. Enforcement: partial `[code]` for the module (`scripts/powershell-module/Docker-BuildAgent.psm1:111`); `[instruction]` for the tool
