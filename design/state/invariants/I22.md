## Statement

**Map-derived environment does not overwrite the process environment.** A value already present in the process environment wins over a value the mapping file produces. Owner: Config, Build types. Enforcement: `[instruction]` — `forge/Common/Base.cs:209` loads the generated file into the process with the library's default overwrite behaviour, which the slice must pin explicitly
